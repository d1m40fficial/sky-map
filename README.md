# Orbita

**Панорама звёздного неба для любой точки Земли.** Звёзды, созвездия, планеты, Луна и Млечный Путь — в браузере.

[**Открыть →**](https://d1m40fficial.github.io/sky-map/)

## Что внутри

- панорамный обзор неба по умолчанию и классический «купол»;
- 100+ ярких звёзд J2000, линии и названия созвездий;
- Солнце, Луна с фазой и планеты;
- Млечный Путь по галактическим координатам;
- выбор города, даты и времени, ускоренное течение неба;
- перетаскивание, масштаб и карточка звезды.

Расчёты — низкоточные астрономические формулы: это планетарий для наглядности, а не астрометрия.

## Стиль

Обсерватория: почти чёрное небо, латунные подписи, антиква для часов и моноширинные координаты.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:5183/sky-map/`.

```bash
npm run check
npm run build   # docs/
```

## Деплой

`docs/` публикуется с `main / docs` на GitHub Pages.
